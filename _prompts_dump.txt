# Фундамент-промпт v4 (ФИНАЛЬНЫЙ для конвейера)

> Использование: подставить https://yandex.ru/maps/org/victoria/112134720311/, прикрепить 5 лучших фото для стилистики,
> вставить каталог всех фото (сборщик делает это автоматически).

---

Сделай продающий одностраничный лендинг для бизнеса по ссылке: https://yandex.ru/maps/org/victoria/112134720311/

## Входные данные
- Ссылка на карточку бизнеса (выше).
- **Категория бизнеса: Салон красоты / парикмахерская / барбершоп.**
- **Якорь (эталон из нашей базы): название: Виктория; город: Калининград; адрес: Калининград, Комсомольская ул., 2А; телефон: +7 (911) 865-44-60**
- 5 фото для стилистики (прикреплены к сообщению) — вытяни из них визуальный язык: палитру, настроение, текстуры.
- Каталог всех реальных фото бизнеса (ниже) — из него бери фото для лендинга. Это единственный источник фото.

## Твоя задача
1. Изучи бизнес по ссылке. Ищи данные именно для ЭТОЙ организации (якорь выше: название + город + адрес). Если найдёшь бизнес с таким же названием, но в другом городе или по другому адресу — это НЕ наш клиент, его данные не использовать. При расхождении данных из других источников с якорем — бери данные якоря (они эталонные), расхождение отметь в отчёте.
2. Сделай лендинг, который выглядит дороже, чем бизнес на самом деле, и продаёт с первого экрана. Обязательна мобильная версия: сайт должен отлично выглядеть и работать и на компьютере, и на телефоне (от 360px ширины экрана).

## Эталон «дорого» (ориентир, не жёсткие рамки)
- Крупные заголовки, очевидная иерархия (самый крупный элемент экрана — заголовок).
- Воздух: большие отступы между секциями, ничего не прилипает к краям.
- 2-3 фирменных цвета + 1 акцентный; тёплые тонированные фоны вперемешку с тёмными секциями.
- Кнопки с глубиной (градиент/тень/hover). Фото обработаны (фильтр/оверлей/рамка).
- Запрещено: серый логотип на светлом, плоские бледные кнопки, чистый белый фон без акцентов, эмодзи, канцелярит, «добро пожаловать», отраслевые клише (например: розовый глянец, «золотые» вензеля, чёрно-красный огонь).

> **Пометка на будущее (A/B):** прогнать версию промпта С этой секцией и БЕЗ неё на одном бизнесе — сравнить результат (дороговизна, структура, перекрытия фото). По итогу решить: оставить, выкинуть или ужать. Пока — оставляем.
## Единственные жёсткие правила (только факты)
- **Телефон, адрес, часы работы** — только реальные, проверенные. Ошибёшься здесь — клиент позвонит не туда.
- **На лендинг выводи только ОДИН основной контакт бизнеса** (телефон записи/администратора). Личные номера сотрудников и мастеров НЕ выводи. Мастеров можно упомянуть текстом (имя + специализация), без номеров.
- **Цены** — только реальные, которые ты нашла. Не нашла цену — пиши «по запросу».
- **Отзывы** — НЕ ищи в интернете и НЕ выдумывай. Сделай блок на 4 карточки (адаптивная сетка 4→2→1) с маркером @@REVIEWS@@ (один раз на весь блок). Реальные отзывы вставит подрядчик.
- **Не выдумывай услуги**, которых нет в карточке или найденных источниках.
- **Проверяемые факты** (телефон, адрес, часы, цены, конкретное время) — только из карточки/источников, никогда не выдумывай.
- **Обещания сервиса** (бесплатная консультация, «перезвоним за N минут», гарантия, стерильность) — допустимы, это продающие офферы бизнеса; подрядчик согласует их с владельцем перед публикацией.
- **Конкретное время записи** («сегодня свободно 17:30», «приходите в 18:00») — НЕ выдумывай: клиент придёт в это время и попадёт в накладку, это проверяемая ложь.
- **Дефицит без конкретики** («осталось N мест», «запись на ближайшие дни разбирают») — допустим как продающая механика, НО только если владелец подтвердил, что готов так отвечать при звонке («разобрали, есть другое время»). Это связка сайт + скрипт продажи.
- Всё остальное (формулировки, офферы, структура, механики) — твоя свобода.

## Фото — ТОЛЬКО из каталога (не ищи фото в интернете)
- Каталог ниже — все реальные фото бизнеса. Для каждого: имя файла, **пиксельные размеры (Ш×В)** и описание содержимого.
- **Используй размеры при вёрстке:** горизонтальные фото (Ш > В) — для широких секций, hero и баннеров; вертикальные (В > Ш) — для карточек, колонок, мобильных блоков; квадратные — для галерей. Соотношение сторон контейнера подбирай под фото, чтобы не обрезать важное и не растягивать (object-fit: cover + правильный aspect-ratio).
- Подбирай по описанию под нужное место (фасад, интерьер, работа, продукция и т.п.).
- В код НЕ вставляй картинки. Вместо каждого фото поставь маркер:
  ```html
  <!-- @@PHOTO:hero@@ описание: что должно быть на фото -->
  <img src="img/PHOTO_hero.jpg" alt="...">
  ```
  Файлы img/PHOTO_*.jpg не создавай — их подставит подрядчик (локальные файлы надёжнее чужих ссылок).
  В описании маркера укажи, что должно быть на фото, и подходящее имя файла из каталога.
- Стоковые фото, чужие URL, CDN, абсолютные пути — запрещены.
- **Вёрстка чистая: фото не должны перекрывать друг друга и текст. Никаких наложений, обрезанных краёв, картинок поверх картинок.**

- Всё остальное (формулировки, офферы, структура, механики) — твоя свобода.

## Фото — ТОЛЬКО из каталога (не ищи фото в интернете)
- Каталог ниже — все реальные фото бизнеса. Для каждого: имя файла, **пиксельные размеры (Ш×В)** и описание содержимого.
- **Используй размеры при вёрстке:** горизонтальные фото (Ш > В) — для широких секций, hero и баннеров; вертикальные (В > Ш) — для карточек, колонок, мобильных блоков; квадратные — для галерей. Соотношение сторон контейнера подбирай под фото, чтобы не обрезать важное и не растягивать (object-fit: cover + правильный aspect-ratio).

  ```html
  <!-- @@PHOTO:hero@@ описание: что должно быть на фото -->
  <img src="img/PHOTO_hero.jpg" alt="...">
  ```
  Файлы img/PHOTO_*.jpg не создавай — их подставит подрядчик (локальные файлы надёжнее чужих ссылок).
  В описании маркера укажи, что должно быть на фото, и подходящее имя файла из каталога.

- **Вёрстка чистая: фото не должны перекрывать друг друга и текст. Никаких наложений, обрезанных краёв, картинок поверх картинок.**
